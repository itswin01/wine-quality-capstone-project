How it works

The application sends the 11 wine measurements to a FastAPI prediction endpoint. The trained regression model then estimates the wine's quality score.

Quality Scale

The dataset uses a quality score from 0 to 10. Higher scores represent wines that received higher quality ratings in the underlying dataset.

Model Pipeline

The model is tracked using MLflow, stored in the MLflow Model Registry, fetched from DagsHub, and packaged into a Docker image for inference.
